# DECISIONS

Running log of engineering decisions that deviate from, refine, or instantiate the
package specification. Precedence rule from `01_MASTER_CODEX_PROMPT.md`: **leakage
prevention + honest reporting + hardware constraints** outrank convenience.

## D001 — Measured hardware differs from the specification's assumption (2026-10-08)

Spec `02_IMPLEMENTATION/00_VPS_24GB_SETUP.md` assumes ≥32 GB RAM and 100–150 GB SSD.
Measured reality on this VPS:

| Resource | Spec assumption | Measured |
|---|---|---|
| GPU | 1× NVIDIA 24 GB | NVIDIA **L4**, 23034 MiB (22.5 GiB) usable |
| System RAM | recommended ≥32 GB | **15 GiB** total (~13 GiB available) |
| CPU | not specified | **4 cores** |
| Free disk | 100–150 GB recommended | **~54 GB** free |

**Consequence:** the spec's own fallback clause applies — "Nếu thấp phải chạy chế độ
compact" (run in compact mode). We therefore:
1. Never hold two large models resident simultaneously (E5 / XLM-R / Laya are loaded,
   used and unloaded phase-by-phase, per the spec's memory-safe schedule).
2. Cap dataset profiles conservatively and treat `full` as opportunistic.
3. Must serialise: no concurrent reader-training + embedding build.

The L4 is compute capability 8.9 (Ada) — bf16 is supported. The spec's "24 GB GPU"
assumption is satisfied for VRAM; the RAM/disk gap is the binding constraint.

## D002 — `uv` for environment management (2026-10-08)

`python3 -m venv` failed: `ensurepip`/`python3.10-venv` is not installed on the image.
`uv` is present and was used to create `.venv` and install dependencies. Resulting
environment is a normal venv; `requirements.lock` is generated by `pip freeze` from
inside it, so reproducibility is unaffected.

## D003 — Laya base checkpoint (2026-10-08)

`laya-train --help` (laya 0.4.0) shows `--base` defaulting to `convaiinnovations/laya`;
the spec's examples use `--base multilingual`. This is resolved at P5 by verifying the
actual accepted values in the installed package and logging the resolved checkpoint ID
and revision. Not decided before P5 — recorded here so it is not silently guessed.

## D004 — Transformers 5.x (2026-10-08)

The resolved dependency set installed `transformers==5.19.0`, a major version newer than
the spec's assumptions. QA-reader training is written against APIs re-verified on this
version rather than copied from spec snippets; any API that no longer exists is reported
in the reader's stage notes instead of being worked around silently.

## D005 — Source dataset licence (2026-10-08)

Per `06_REFERENCES/01_ASSUMPTIONS_LICENSES_AND_RISKS.md` and the dataset section of
`01_SPECIFICATIONS/04_DATASET_VALIDITY_AND_LEAKAGE.md`, the redistribution licence of
`taidng/UIT-ViQuAD2.0` is **not verified**. Raw data is therefore never committed and
`data/` is git-ignored. Only derived, aggregate diagnostics are reported.
